# Feature list document

Create a downloadable, branded document listing every feature of the Team Huntington Hub.

## What you get
- A PDF named `team-huntington-hub-features.pdf`, saved to your Files so you can download or email it
- Title page: site name, domain, date
- One section per area: Sign-in & security, Rider & volunteer experience, Fundraising (including the approval flow diagram), Events & messaging, Leadership, Vendor CRM, Super User / Admin console, Behind the scenes
- A short role-access table showing who can see what (participant, captain, vendor access, admin, Super User)
- Huntington brand colors to match the site

## Quality check
- Every page is turned into an image and checked for cut-off text or broken layout before it's delivered

## Technical details
- Generated with a Python script in /tmp, output to /mnt/documents
- No changes to the app itself
